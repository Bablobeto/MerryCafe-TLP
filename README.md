## About
MerryCafe-TLP is aimed at building a website for a fictional Cafe to help promote their service. It is to promote their café menu such as coffee, drinks, and snacks. 

## Technology
- HTML
- CSS
- Javascript

## Features
- Home page
- About Section
- Category Section
- Product Section
- Contact Section
